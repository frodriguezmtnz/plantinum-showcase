# 🏆 Platinum Showcase

Bienvenido a **Platinum Showcase**, el centro comunitario definitivo para que los entusiastas de PlayStation compartan, celebren y descubran el logro más codiciado de los videojuegos: el Trofeo de Platino.

Esta es una aplicación web construida con Next.js donde los usuarios pueden subir capturas de pantalla de sus trofeos de platino, votar por sus favoritos y escalar en las tablas de clasificación mensuales para entrar en el Salón de la Fama.

## ✨ Características

- **Galería de Trofeos:** Explora una vasta colección de capturas de pantalla de trofeos de platino de la comunidad.
- **Sube y Muestra:** Comparte tus propios logros subiendo tus capturas de pantalla de platino.
- **Sistema de Votación:** Vota por tus platinos favoritos y ayúdalos a subir de rango.
- **Salón de la Fama:** Una celebración mensual de los platinos más votados.
- **Perfiles de Usuario:** Muestra toda tu colección y ve las estadísticas de otros cazadores.
- **Protección de Spoilers:** Las capturas de pantalla pueden marcarse como spoilers para no arruinar la historia a otros.

## 🛠️ Stack Tecnológico

Este proyecto está construido con un stack tecnológico moderno y potente:

- **Framework:** [Next.js](https://nextjs.org/) (con App Router)
- **Librería UI:** [React](https://react.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Componentes UI:** [ShadCN UI](https://ui.shadcn.com/)
- **Funcionalidades IA:** [Genkit de Google](https://firebase.google.com/docs/genkit)
- **Iconos:** [Lucide React](https://lucide.dev/)

## 🚀 Empezando

Para obtener una copia local y ponerla en marcha, sigue estos sencillos pasos.

### Prerrequisitos

- [Node.js](https://nodejs.org/) (v18 o posterior recomendado)
- [npm](https://www.npmjs.com/)

### Instalación

1.  **Instala las dependencias:**
    ```sh
    npm install
    ```

2.  **Configura las variables de entorno:**
    Crea un archivo `.env` en la raíz del proyecto si necesitas añadir variables de entorno personalizadas.

3.  **Ejecuta el servidor de desarrollo:**
    ```sh
    npm run dev
    ```

Abre [http://localhost:9002](http://localhost:9002) con tu navegador para ver el resultado.
